HASE study | Codex quick start

You need Python 3.9+ and a current Codex CLI signed in to your own ChatGPT account.
Read the study consent form first.

1. Download the kit (https://github.com/NinaCheung123/hase-participant-kit, green Code
   button, Download ZIP) and unzip it. Open Terminal and go into the folder that
   contains study.py. On a Mac, if you unzipped it in Downloads:

   cd ~/Downloads/hase-participant-kit-main
   codex login status

   If you are signed out, run codex login.

2. Start the study page:

   python3 study.py web --codex-logs

   Your browser opens a page that runs only on this computer. Keep the terminal open.
   The page shows every selected message and every task from your own chats; untick
   anything you do not want sent. Then follow the page to the end.

   If your Codex history is somewhere else (CODEX_HOME, or archived chats), point to
   the folder that contains it, for example:  python3 study.py web --codex-logs ~/.codex

3. At the end, upload only my-study/study_files.zip at
   https://drive.switch.ch/index.php/s/DpdfHjo9pmGMpdJ (no login needed).
   Your messages, tasks, answers and skill texts stay on your computer.

If the page closes or something stops, run the same command again; your progress is kept.
Prefer the terminal? See "The same in the terminal" in README.md.
